# Юнеман — вертикалки

Дашборд просмотров вертикальных роликов в YouTube Shorts, Instagram Reels, VK Клипах и TikTok.

- `index.html` — сам сайт, считает всё в браузере.
- `data.json` — цифры. Одна строка — один ролик в одном замере.

## Как обновлять

Добавьте в `data.json` строки с новой датой `snapshot` (ГГГГ-ММ-ДД). Для каждого ролика сайт берёт последний замер за месяц, а месяц определяется по дате замера.

```json
{"snapshot": "2026-11-04", "id": "yt01", "platform": "YouTube", "title": "Название", "topic": "Тема", "published": "2026-10-27", "views": 5000, "likes": 272, "comments": 26, "shares": null}
```

- `id` у одного и того же ролика между замерами не меняется.
- `platform` — одно из значений: `YouTube`, `Instagram`, `VK`, `TikTok`.
- `topic` одинаковый у одного ролика на разных площадках, по нему строится таблица «Один ролик — разные площадки».
- «Залетел» значит ×1,5 к медиане просмотров площадки за месяц.
